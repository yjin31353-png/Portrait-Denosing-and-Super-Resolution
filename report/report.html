二、NAFNet —— 模型架构

2.1 核心创新

NAFNet (Nonlinear Activation Free Network) 的核心发现是：传统的非线性激活函数（Sigmoid、ReLU、GELU、Softmax 等）可以用乘法运算替代，甚至直接移除。这带来了更简洁高效的网络结构。

2.2 网络结构

Input (H×W×3)
    │
    ├── Intro Conv (3×3, c→width)
    │
    ├── [Encoder × N stages]
    │     ├── NAFBlock × n
    │     └── Downsample (stride-2 Conv)
    │
    ├── Middle Blocks (NAFBlock × m)
    │
    ├── [Decoder × N stages]
    │     ├── Upsample (PixelShuffle 2×)
    │     ├── Skip Connection (+ encoder)
    │     └── NAFBlock × n
    │
    ├── Ending Conv (3×3, width→c)
    ├── Global Residual
    │
Output (H×W×3)

2.3 NAFBlock 结构

SimpleGate：将特征沿通道分成两半，逐元素相乘。无参数、无激活函数。

SimpleGate(x) = x₁ · x₂  (x = [x₁, x₂] split along channel dim)

Simplified Channel Attention (SCA)：全局平均池化 → 1×1 Conv。相比传统 SE 模块，去掉了 ReLU 和 Sigmoid。

SCA(x) = Conv(GAP(x))
Input
    │
    ├── LayerNorm
    ├── 1×1 Conv (expand ×DW_Expand)
    ├── 3×3 Depthwise Conv
    ├── SimpleGate (chunk → multiply)
    ├── × SCA (attention)
    ├── 1×1 Conv (project back)
    ├── Dropout
    ├── + Input × β (残差)
    │
    ├── LayerNorm
    ├── 1×1 Conv (expand ×FFN_Expand)
    ├── SimpleGate
    ├── 1×1 Conv (project back)
    ├── Dropout
    ├── + Input × γ (残差)
    │
Output

三、Real-ESRGAN —— 模型架构

3.1 核心思想

Real-ESRGAN 使用纯合成数据训练，通过更复杂的降质模拟（高阶退化模型）来桥接合成数据与真实数据之间的差异。
